# Skill 验收用例 / Skill acceptance cases

用这些用例评估可观察行为，而不是措辞是否完全相同。Use these cases to assess observable behavior rather than wording similarity.

| Skill | Minimal scenario | Observable pass condition |
|---|---|---|
| `socratic-questioning` | A vague career concern | Asks one decision-changing question, not a list or advice. |
| `dual-layer-explanation` | A technical concept | Gives coherent beginner/professional layers and misconception checks. |
| `reverse-engineering` | A supplied page | Separates visible evidence from inferred rationale. |
| `deep-research` | A company history and peer analysis | States scope, dates claims, and separates facts from scenarios. |
| `fact-check` | A quantified causal claim | Splits fact/inference/value and reports evidence limits. |
| `expert-panel` | A cross-functional decision | Uses complementary simulated lenses and names disagreement. |
| `first-principles` | A legacy process redesign | Preserves real constraints while challenging assumptions. |
| `cross-domain-transfer` | A constrained service problem | Transfers a mechanism and names mismatch risk. |
| `steelman-debate` | Two explicit options | Makes strong cases for both and identifies the pivotal variable. |
| `minimum-experiment` | A new idea | Defines one reversible test, metric, threshold, and stop rule. |
| `talent-discovery` | A strengths exploration | Uses self-report evidence and offers an editable recovery summary. |
| `life-design` | A five-year direction question | Keeps user agency, produces multiple viable directions, and handles consent. |

## 语言行为 / Language behavior

- 中文请求默认输出中文；English requests default to English.
- 当用户要求双语输出或自然混用两种语言时，对关键结论、术语和行动项给出中英对照；When bilingual output is requested or naturally needed, provide Chinese-English pairs for key conclusions, terms, and actions.
- 不擅自翻译代码、专有名词、来源标题、法律/标准名称或用户提供的引用；Do not translate exact identifiers, titles, legal or standards names, or user quotations unless asked.
