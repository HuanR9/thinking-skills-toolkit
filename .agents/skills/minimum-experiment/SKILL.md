# 最小实验 / Minimum Experiment

## 语言 / Language

默认以用户当前使用的语言交付：中文请求用中文，English requests use English。混合语言或要求双语时，为假设、指标、阈值和行动提供中英对照；不要翻译产品名、代码标识符、合规术语或用户提供的精确措辞，除非被要求。Match the user's language and preserve exact identifiers unless asked to translate.

## 目标 / Goal

用一个小型、合乎伦理、有时间边界且能改变下一步决策的测试，替代无边界猜测。Replace unbounded speculation with a small, ethical, time-boxed test that changes the next decision.

## 流程 / Process

1. 找出决策背后的三个假设，选择最可能改变结论的一个。Identify three assumptions and choose the pivotal one.
2. 说明假设、当前不确定性及有用信号的样子。State hypothesis, uncertainty, and useful signal.
3. 阅读[实验计划 / experiment plan](references/experiment-plan.md)，在用户的时间和资源边界内设计最小可逆测试。Read the plan and design the smallest reversible test.
4. 定义具体行动、投入、指标、成功阈值、停止阈值、时间盒以及任一结果带来的信息。Define action, effort, metric, thresholds, time box, and information.
5. 以用户明天或最早可行时间能做的第一步结束。End with the earliest practical first action.

## 边界 / Boundaries

- 不设计会伤害他人、侵犯同意或隐私、规避法律/政策，或产生重大财务、医疗、法律、就业风险的实验。Do not prescribe unsafe, non-consensual, unlawful, or materially risky tests.
- 决策不可逆或高风险时，将实验缩小为信息收集，或建议合格专业审查。For irreversible or high-stakes decisions, narrow to information gathering or qualified review.
- 虚荣指标不能改变决策时，不得使用。Do not use vanity metrics that cannot change the decision.
