# Experiment plan

| Field | Requirement |
|---|---|
| Decision | What decision will this test inform? |
| Pivotal assumption | One falsifiable belief most likely to change the decision. |
| Hypothesis | If we do X, then Y should happen under Z conditions. |
| Minimum action | The smallest reversible action that can generate a signal. |
| Inputs | Time, money, access, people, and permissions required. |
| Metric | Observable result tied to the hypothesis. |
| Continue threshold | Result that supports the next commitment. |
| Stop threshold | Result that warrants stopping, changing, or gathering more evidence. |
| Time box | The latest date/time for reading the result. |
| Update rule | How each outcome changes the next decision. |
