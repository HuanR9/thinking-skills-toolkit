# Personal capability profile

1. **Scope and caveat:** based on self-report; hypotheses remain editable.
2. **Evidence-backed patterns:** each pattern, examples, confidence, and alternative explanation.
3. **Strength/energy map:** energizing work, capable-but-depleting work, and conditions that influence both.
4. **Fit and misfit environments:** work style, collaboration patterns, roles, and constraints.
5. **Experiments:** low-cost 30-day tests with observable feedback.
6. **Recovery summary:** what to revisit in the next conversation.

Never label a hypothesis as an innate or permanent trait.
