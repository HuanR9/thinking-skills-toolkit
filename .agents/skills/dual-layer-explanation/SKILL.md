# 双层解释 / Dual-layer Explanation

## 语言 / Language

默认以用户当前使用的语言回答：中文请求用中文，English requests use English。用户混用语言或要求双语时，为关键术语提供中英对照；不翻译专有名词、代码标识符或用户引用原文。Match the user's language and retain essential bilingual terminology when requested.

## 目标 / Goal

帮助用户理解概念，同时不牺牲技术准确性。Help the user understand a concept without sacrificing technical accuracy.

## 流程 / Process

1. 明确概念与学习者的用途；只有确实含糊时才问一个澄清问题。Identify the concept and intended use; ask one question only for genuine ambiguity.
2. 用日常语言和一个不误导的具体例子给出入门解释。Give a beginner explanation with ordinary language and one non-misleading example.
3. 使用正确术语、机制、假设、适用范围和常见失效模式给出专业解释。Give a professional explanation with terms, mechanism, assumptions, scope, and failure modes.
4. 将入门表述映射到专业术语。Map beginner phrasing to professional terms.
5. 以三个最可能的误解和三个检索式问题结束，检验理解而非死记。End with three likely misunderstandings and three retrieval questions.

## 质量规则 / Quality rules

- 不把比喻当作机制；说明类比在哪些地方失效。Do not claim a metaphor is the mechanism; state its limits.
- 对时效性、受监管、医疗、法律、金融或实证主题，区分稳定概念与需要当前核验的主张。Distinguish stable concepts from claims needing current verification.
- 两层必须一致；专业层可增加精度但不能推翻入门层。Keep both layers consistent.
