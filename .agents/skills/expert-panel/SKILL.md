# 专家视角小组 / Expert Panel

## 语言 / Language

默认以用户当前使用的语言回答：中文请求用中文，English requests use English。混合语言或要求双语时，为视角名称、分歧和结论提供中英对照；不要把虚构视角伪装成真实人物、真实引语或翻译过的来源。Match the user's language and retain source identities accurately.

## 目标 / Goal

在真正不同的分析视角之间形成建设性张力，再把分歧转化为可行动、有边界的建议。Generate constructive tension among distinct lenses, then turn disagreement into an actionable, bounded recommendation.

## 输入确认 / Intake

确认问题、已知事实、目标和真实约束。若一个缺失细节会改变视角选择，只问这一个问题并等待。Confirm problem, facts, goal, and constraints; ask only the one missing detail that changes lens selection.

## 流程 / Process

1. 选择三种互补的**模拟分析视角**，说明各自必要性，避免角色重叠。Select three complementary simulated perspectives and explain why each is needed.
2. 每个视角都要重述问题、推荐路径、指出他者可能遗漏的风险，并说明会改变其看法的证据。Have each lens reframe, recommend, flag a missed risk, and name updating evidence.
3. 进行善意交叉质询，找出共同事实、真实分歧及其底层假设。Cross-examine for shared facts, real disagreements, and assumptions.
4. 综合出推荐路径、适用条件、最大风险、退出条件和第一步行动。Synthesize path, conditions, largest risk, exit condition, and first action.
5. 关键不确定性仍存在时，推荐最小实验，而不是假装精确。Recommend a minimal experiment when pivotal uncertainty remains.

## 边界 / Boundaries

- 明确说明这是模型生成的视角，不是真人意见或专业建议。State that perspectives are model-generated, not real expert advice.
- 不模仿具名人物，也不伪造资历、引文或独立研究。Do not imitate named people or fabricate credentials, citations, or research.
- 角色可能重复或综合影响高风险选择时，阅读[小组协议 / panel protocol](references/panel-protocol.md)。Read the panel protocol when roles could overlap or stakes are high.
