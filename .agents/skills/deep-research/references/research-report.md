# 研究报告结构 / Research report schema

1. **核心结论 / Core conclusion：**简洁、有条件、尊重证据。
2. **范围与方法 / Scope and method：**对象、截止日期、纳入选择与关键缺口。
3. **时间线 / Timeline：**起源、转折点、成败事件与路径依赖。
4. **比较表 / Comparative table：**一致维度、优点、弱点、采用和放弃原因。
5. **分析 / Analysis：**在对应位置区分事实、推断与观点。
6. **未来情景 / Future scenarios：**三条可能路径、前提与早期信号。
7. **开放问题 / Open questions：**需要更多证据或用户决策的主张。
8. **来源注记 / Source notes：**在所支持主张附近标注来源和日期。
