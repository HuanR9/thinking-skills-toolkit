# 最强论证辩论 / Steelman Debate

## 语言 / Language

默认以用户当前使用的语言回答：中文请求用中文，English requests use English。混合语言或要求双语时，为选项、评价维度和条件性建议提供中英对照；不翻译合同条款、代码标识符或用户引用原文，除非用户要求。Match the user's language and preserve exact source wording unless translation is requested.

## 目标 / Goal

通过检验每个方向最强的论点，让用户看清决策；不要制造表面均衡。Make the decision legible by testing the best case for each direction, not manufacturing balance.

## 输入确认 / Intake

确认决策、选项、目标、约束和截止时间。若一个缺失信息就可能颠倒结果，只问一个有区分度的问题并等待。Confirm decision, options, objective, constraints, and deadline; ask one discriminating question if needed.

## 分析 / Analysis

对每个选项，给出其最强论证、最适用条件、最大收益与风险、最有力的善意反驳，以及会削弱或加强它的证据。For each option, provide its strongest case, conditions, gain, risk, objection, and updating evidence.

然后识别真正分歧、隐藏假设、会改变决策的变量和仍缺失的信息。用户补齐关键答案后，给出清晰的条件性建议、适用边界与下一步行动。Then identify disagreements and missing information; after key input, give a conditional recommendation and action.

## 边界 / Boundaries

- 当证据、风险或可逆性不对称时，不强行平分权重。Do not force equal weight under asymmetry.
- 不把价值取舍当事实争议，应如实点明价值冲突。Name value tradeoffs honestly.
- 关键不确定性可检验时推荐 `$minimum-experiment`；论证依赖有争议事实时推荐 `$fact-check`。Recommend the appropriate follow-on Skill.
